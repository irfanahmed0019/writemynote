# WriteMyNotes

A college note marketplace: post a request to get your records written, connect with writers and close the deal. Like Upwork, but for your campus.

## Features

- Marketplace of writing requests with request detail pages
- Post a request and chat with writers
- Writer profiles and an activity feed
- Mode selection for requesters and writers
- Admin dashboard
- Installable as an app (install page)

## Tech stack

- React and TypeScript with Vite
- Tailwind CSS and shadcn/ui
- Supabase
- TanStack Query and React Router

## Run locally

```sh
git clone https://github.com/irfanahmed0019/writemynote.git
cd writemynote
npm install
npm run dev
```
